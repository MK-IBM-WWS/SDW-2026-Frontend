# Проверки лабораторной работы 7

Выполнено при подготовке архива:

- Чистая установка зависимостей `npm ci` по включённому lock-файлу — успешно.
- `npm run build` — TypeScript и локальная Vite-сборка без ошибок.
- `npm run build:pages -- cloud-tariffs-lab7` — отдельная mock-сборка с base репозитория, manifest, SW, PNG-иконками, 404.html и .nojekyll.
- React DOM-проверка: 4 опубликованных mock-тарифа → фильтр до 1000 ₽ → 2 тарифа → Подробнее → возврат с прежним значением фильтра; параметры записываются в sessionStorage.
- React DOM-проверка с тестовым HTTP API: вход, карточка владельца, лента, открытие добавления и создание черновика с переходом к форме публикации.
- Проверка обработчиков сгенерированного Service Worker: предварительное кеширование файлов, возврат HTML для офлайн-маршрута, офлайн-изображения и видео; Range 0–99, суффиксный Range и 416 для недоступного диапазона; запросы API и MinIO исключены из кеша.
- Интеграционная проверка Node.js по HTTPS с доверенным тестовым сертификатом: HTML-маршрут SPA, корректный MIME SW, 404 отсутствующего JS, Range MP4, POST JSON, Bearer-заголовок, Secure cookie, параметры страницы и фильтра; путь, query и подписанный Host MinIO сохраняются.

Проверки DOM и HTTP использовали временные тестовые upstream-сервисы. Полная связка с вашей БД, Redis и MinIO, реальный Android и публичный GitHub Pages в этой среде не проверялись. Публикацию вы выполняете самостоятельно по инструкции. Браузер здесь не смог подключиться к тестовому серверу, поэтому визуальная проверка при разных ширинах и установка PWA на Android требуют выполнения на ваших устройствах.

Перед защитой пройдите `SCREENSHOTS_LAB7.md`; это одновременно сценарий ручной проверки реального развёртывания. Не выдавайте локальную гостевую mock-подмену за работу бэкенда: для снимков 8–12 нужны работающие сервисы и успешная аутентификация.
