# Лабораторная работа 7 — адаптивность, PWA, GitHub Pages и HTTPS

Изменён только фронтенд. Используйте без изменений бэкенд из `SDW-2026-Backend(4).zip`.

- Плитка: 1 / 2 / 3 / 4 колонки при ширине <480 / ≥480 / ≥768 / ≥1200 px.
- Адаптированы лента, добавление/черновик, вход и навигация.
- Кнопка со стрелкой открывает тариф в существующей ленте; вкладка «Плитка» возвращает к прежнему фильтру. Фильтр и страница хранятся в Redux и sessionStorage.
- PWA: manifest, обычные и maskable PNG-иконки, собственный Service Worker с кешем приложения и локального mock-медиа; работает после сборки. API, JWT и MinIO в кеш SW не попадают.
- Pages: отдельная сборка `dist-pages`, только mock, без запросов к API. Поддерживается `/имя-репозитория/` и прямое открытие маршрутов через `404.html`.
- Локально: Node.js принимает HTTPS, отдаёт `dist`, проксирует `/api` в Go и `/s3` в MinIO. Подпись MinIO сохраняется.

Версия 3.0.1 исправляет HTTP 404 на Pages: флаг mock имеет корректный тип, на `*.github.io` API не вызывается. Перед публикацией выполняется `check:environment`.

Версия 3.0.2 убирает информационные плашки на Pages и ссылку «К тарифам» в ленте; на карточке снова только круглая кнопка со стрелкой.

Версия 3.0.3 меняет только отображение Pages: убран текст на входе, оболочка и лента занимают всю ширину, на узких вертикальных экранах до 767 px одна колонка. Отдельные стили находятся в `src/pages.css` и действуют только внутри `.phone--pages`; локальные стили и HTTPS-прокси не менялись.

## Основные команды из папки frontend

```bash
npm ci
npm run build
npm run certs -- 10.133.98.180
npm run start:https
```

Подставьте IP ноутбука, установите `certs/local-ca.crt` на Android и заранее запустите бэкенд. Открывайте `https://IP:3000`.

Для Pages после настройки GitHub:

```bash
npm run deploy -- cloud-tariffs-lab7
```

Здесь `cloud-tariffs-lab7` — настоящее имя вашего репозитория. Команда сама создаёт mock-сборку и публикует её в ветку `gh-pages`.

`npm run dev` оставлен для обычной разработки по HTTP. Для демонстрации PWA и HTTPS используйте собранное приложение, а не dev-сервер.
