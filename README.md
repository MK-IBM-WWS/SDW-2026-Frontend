# Лабораторная работа 7 — адаптивность, PWA, GitHub Pages и HTTPS

## Основные команды из папки frontend

```bash
npm ci
npm run build
npm run certs -- 10.133.98.180 или 192.168.10.104 - всегда можно узнать с помощью ip a
npm run start:https
```

Установить `certs/local-ca.crt` на Android. Открывайть `https://IP:3000`.

Для Pages после настройки GitHub:

```bash
npm run deploy -- SDW-2026-Frontend
```
