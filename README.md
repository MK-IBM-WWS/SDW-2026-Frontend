# Облачные тарифы — лабораторная №6

React + TypeScript + React Bootstrap + Redux Toolkit + Axios.

## Быстрый запуск

Node.js 24 LTS (либо 22.12+ в ветке 22):

```bash
cp -n .env.example .env
npm ci
npm run dev -- --force
```

Открыть http://localhost:3000. При выключенном API доступны гостевые mock-карточки.
Для работы с БД/загрузки файлов нужен Go-бэкенд ЛР4 и PostgreSQL/MinIO/Redis.
Адреса upstream задаются в `.env`, пример включён. Два proxy в vite.config.ts:
`/api` для Go, `/s3` для MinIO. Подписанные URL сохраняют Host и query-строку.
Сбой соединения proxy с API возвращается как 503; реальные ошибки API не меняются.

```bash
npm run generate-api
npm run typecheck
npm run build
```

`generate-api` повторно создаёт Axios-клиент из `src/api/swagger.json`.
Свежая схема работающего бэкенда:
`API_SCHEMA_URL=http://localhost:8080/swagger/doc.json npm run generate-api`.

## Страницы и действия

| Адрес | Содержимое | Действия |
| --- | --- | --- |
| `/tariffs` | Плитка опубликованных тарифов, максимальная цена, логин | Передвинуть слайдер, применить лупой, открыть карточку; пользователь удаляет свои тарифы крестиком поверх картинки |
| `/tariffs/feed` | Один тариф, видео, описание, цена, RAM, число лайков | Раскрыть описание, перейти к следующему; пользователь ставит/отменяет лайк |
| `/tariffs/draft` | Свой черновик либо форма нового тарифа | Выбрать фото/видео независимо, указать название и «Далее»; заполнить описание/цену/RAM и опубликовать; удалить черновик |
| `/login` | Форма логина и пароля | Выполнить настоящий вход по API |

Панель внизу: Лента, Добавление, Плитка, Вход/Выход. Добавление доступно после
входа. Крестик удаления расположен в правом верхнем углу поверх картинки
и показывается только при is_owner=1. Гость может читать данные
и фильтровать их. Удалённые и неопубликованные тарифы отсутствуют на плитке/в ленте.
Файлы передаются как multipart, а не как URL. Пустые и недоступные медиа
заменяются локальными `public/media/example.jpg` и `example.mp4`.

## Redux и HTTP

`tariffs` хранит выбранный/применённый фильтры, список, карточку ленты и черновик.
`tariffUser` хранит состояние интерфейса после входа, логин и ID пользователя.
`tariffInterface` хранит счётчик запросов и сообщение ошибки.

Операции тарифов выполняются через createAsyncThunk и сгенерированные методы
`src/api/generated/TariffsApi.ts`. Axios используется в HTTP-клиенте.
Вход/выход — прямые вызовы Axios в функциональных компонентах, после них
отправляются обычные Redux actions. Thunk подключён configureStore по умолчанию.
Redux DevTools поддерживается стандартной конфигурацией.

Отдельной кнопки обновления нет. Для получения внешних изменений списка
обновите страницу средствами браузера (F5/Ctrl+R). Возврат из ленты на плитку
сам по себе не перезагружает список. Запросы при применении фильтра и смене
пользователя сохраняются; публикация, лайки и удаление обновляют данные Redux
по результату соответствующего действия.

При переходах внутри SPA фильтр сохраняется. При выходе сбрасывается.
**По заданию защиты ЛР6** после F5 Redux заново становится гостевым, JWT остаётся
в localStorage (`cloud_tariffs_jwt`), но автоматически для гостевых запросов не
используется. При явном выходе JWT отзывается на сервере и удаляется из браузера.

Пока есть запросы, отображается Spinner, кнопки отключены, область интерфейса
имеет inert. Моки используются только гостем при сетевом сбое или 502/503/504;
настоящие ошибки валидации, авторизации и сервера показываются пользователю.
